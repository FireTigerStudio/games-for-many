# HTML5 游戏聚合站：6 个月项目路线图

> 文档状态：阶段 0 执行草案（采用 manual-first 冷启动方案）  
> 更新日期：2026-08-10  
> 目标：面向美国市场的英文站，6 个月内达到 5,000 UV/天，并建立页面广告与游戏内广告两条合规收入线。

## 1. 先给结论

不建议首发时同时做 io、休闲、塔防、派对四个大类。新站更可行的路径是：先选择 **一个有稳定搜索需求、合法游戏供给充足、竞争强度可控的垂类**，用 30–50 款经过人工试玩和编辑的游戏建立主题权威；验证收录、排名、留存与广告数据后，再扩展相邻分类。

首站垂类已确定为 **2 player browser games / 2 player games online**，优先收录同键盘、本地双人游戏，其次是无聊天、无账号、无用户生成内容的在线合作或对战游戏。定位为 `casual gamers, teens and adults`，不以 13 岁以下儿童为目标人群。完整依据见 `docs/00a-niche-decision-record.md`。

品牌已确定为 **Games for Many**，主域名为 **gamesformany.com**。品牌名称用于承载今后从双人游戏向 3–4 人、派对及精选休闲多人游戏扩展；首发首页和核心分类仍明确聚焦双人浏览器游戏，不把 `games for many` 当作主要 SEO 关键词。

最终选择标准不是“哪个词搜索量最大”，而是以下加权得分：

| 因素 | 权重 | 合格线 |
|---|---:|---|
| 可合法嵌入且质量合格的游戏供给 | 30% | 首批至少 30 款，90 天内可扩至 60 款 |
| 美国市场低/中难度非品牌词机会 | 25% | 至少 20 个相关词 KD ≤ 35（Semrush 口径） |
| 搜索意图与浏览器游戏匹配 | 20% | SERP 中存在可直接游玩的独立站/聚合站 |
| 内容可拓展性 | 15% | 至少 12 篇不重复的攻略/榜单主题 |
| 广告与安全适配 | 10% | 无成人、赌博、重度血腥、未授权 IP 依赖 |

## 2. 商业模式与优先级

### 2.1 第一收入线：游戏源内置广告分成

站点通过供应商后台取得官方 iframe/API 嵌入代码；游戏供应商在游戏自然节点展示广告，并按协议与站长分成。冷启动改为 **manual-first、API-later**：先从已登记域名的 GameMonetize 官方目录手工筛选 10 款合规双人游戏并记录官方 iframe，完成可审核 MVP；GamePix 取得书面同意和 Publisher `sid` 后再接入；GameDistribution 因新域名流量不足拒绝本次申请，待产生真实流量后重新申请。具体条款以各平台批准后的当期协议为准。

这条收入线的优点是无需自行改游戏代码；缺点是收入与供应商填充率、玩家地区、会话时长及分成条款绑定，站长对体验控制有限。

### 2.2 第二收入线：页面展示广告

游戏页正文、分类页和博客页使用 AdSense 展示广告。游戏页是高误点风险页面：Google 建议内容广告与游戏区域保持至少 150px 距离，不得让 Play 按钮通向广告主导的过渡页，也不得用广告阻挡开始游戏。首发版本只预留广告位，不在获得批准前加载真实广告代码。

### 2.3 后续收入线（有流量后再评估）

- 直接广告/赞助专区：只接受与休闲游戏受众相关且合规的广告主，明确标注 Sponsored。
- 自有游戏或独家授权：中长期毛利和差异化更好，但不属于前 90 天范围。
- 合规联盟营销：仅在攻略内容中自然推荐硬件或服务；不为提高 CPC 制造无关页面。

**不采用：** 抓取未授权游戏、盗链素材、强制弹窗/弹底、诱导点击、购买机器人流量、下载器、学校解锁词、未授权 IP 流量页。

## 3. 授权源边界

| 来源 | 当前可规划的用途 | 上线前必须取得/保存的证据 |
|---|---|---|
| GameMonetize（冷启动源） | 手工选择首批 10 款并使用官方 iframe；不批量抓取或直接上线目录 | 账号、已登记域名、ads.txt、每款游戏官方嵌入 URL、当期条款、人工内容安全记录 |
| GamePix（待批准备用源） | 取得书面同意和 Publisher `sid` 后，先手工嵌入，后续再使用 JSON API | Publisher 批准、`sid`、API/嵌入许可、登记域名、每款游戏来源记录、当期条款 |
| GameDistribution（延后） | 当前不使用其游戏；网站获得真实流量后重新申请 Publisher | Publisher 批准、登记域名、每款游戏官方嵌入 URL、当期条款/分成证据 |
| CrazyGames | 主要作为自有游戏的发布渠道；第三方游戏只有页面明确提供官方 Embed 或获得书面许可时才嵌入 | Embed 按钮/许可证明；不可复制其 CDN 地址或把目录当开放 feed |
| 自有/直接授权游戏 | 文件自托管或按合同嵌入 | 权利人身份、分发区域/期限、广告权、素材使用权 |

“免费游玩”“可 iframe”与“开源”是三件不同的事。任何游戏在进入 `games.csv` 前都要有 `license_status=verified` 的内部审核记录；阶段 1 的 CSV 模板会加入许可证据字段建议，但不会改变用户指定的核心字段。

## 5. 阶段门槛与 KPI

5,000 UV/天是目标，不是可保证结果。前 90 天优先验证供给、收录与用户价值，避免为了页数制造薄内容。

| 阶段 | 领先指标 | 建议门槛 |
|---|---|---|
| 上线前 | 合法游戏、原创内容、技术质量 | ≥30 款已验证游戏；核心路由无错误；法律页完整 |
| 上线 30 天 | 收录、曝光、启动体验 | 核心页面被发现/收录；游戏启动成功率 ≥98%（自测与监控口径） |
| 上线 60 天 | 查询增长、用户行为 | 非品牌曝光逐周增长；形成至少 1 个有稳定曝光的主题集群 |
| 上线 90 天 | 可复制性 | 至少 10 个页面获得自然点击或有效引荐；知道哪些内容/游戏值得扩张 |
| 6 个月 | 业务结果 | 目标 5,000 UV/天；若未达到，以自然流量趋势、回访与单位会话收益决定是否继续 |

核心看板：自然 UV、非品牌点击/曝光、索引率、Top 10/20 关键词数、游戏启动率、有效游戏会话、每会话页数、回访率、页面广告 session RPM、游戏源每千次启动收入、按国家/设备拆分的收益、LCP/INP/CLS。

## 6. 本地与云端资产放置建议

当前阶段只规划，不创建工程环境。进入开发阶段后采用以下边界：

- **本地工作区：** `C:\AppDev\ioGame`，项目依赖只安装在该项目内；不全局安装 npm 包。
- **敏感信息：** 本地 `.env.local`，Vercel Environment Variables 存生产值；绝不提交 GitHub。
- **研究原始文件：** 后续统一放 `/research/raw/semrush/`、`/research/raw/trends/`；当前根目录已有导出文件先不移动，避免擅自整理用户资产。
- **用户填表：** `/data/`；模板为 `/data/templates/`；生成后的静态数据建议为 `/data/generated/`。
- **授权证据：** 建议放私有存储或私有仓库的 `/compliance/licenses/`，不要公开含账号或合同信息的文件。
- **代码：** GitHub 私有仓库起步；稳定后是否公开由站长决定。
- **部署：** GitHub → Vercel；Cloudflare 先只做 DNS/注册商层，避免首发时叠加复杂缓存规则。

## 7. 品牌与域名决策

| 项目 | 已确认值 |
|---|---|
| 品牌名 | `Games for Many` |
| 主域名 | `gamesformany.com` |
| 首发首页主题 | Free 2 Player Games Online / 2 Player Browser Games |
| 后续可扩展范围 | 3–4 player、party、selected casual multiplayer |

`gamesformany.com` 是品牌域名，不是精确匹配关键词域名。Semrush 中 `games for many` 的搜索意图偏大型聚会/桌游，不能用作首页核心目标词；首页 title、H1、正文和内链应围绕双人浏览器游戏的真实意图展开。

购买前已完成初步核验：USPTO 精确词查询未发现相同有效结果；Internet Archive 未发现历史快照；Semrush 未发现历史自然排名或反向链接数据。以上是项目级初筛，不构成正式商标法律意见。

### 域名选择规则（保留供未来新增域名使用）

优先选择可品牌化的 `.com`：6–12 个字母或两个简短英文词，易拼写、易读、无连字符/数字，不含第三方商标，不把未来限制死在单款游戏上。Exact-match domain 不是选择理由；域名应能承载首个垂类及相邻扩展。

域名确定前做四项核验：

1. USPTO TESS/Trademark Search 与 WIPO Global Brand Database 查近似商标。
2. Google 搜索名称和拼写变体，排除已有游戏、应用或成人/博彩含义。
3. Internet Archive 检查历史用途；Semrush/Ahrefs 查历史自然词与外链垃圾度。
4. 确认主要社媒 handle，并检查是否容易口述和输入。

未来如购买防御性域名或新品牌，仍按以上四项核验；商标结论应由专业人士确认。

## 9. 关键风险与应对

| 风险 | 早期信号 | 应对 |
|---|---|---|
| 游戏授权不清 | 只有可玩链接，没有官方 embed/后台记录 | 不入库、不上线；保留许可证据 |
| 聚合页内容过薄 | 大量模板描述、页面不收录 | 小批发布；加入真实试玩、控制、机制与推荐理由 |
| 广告误点/无效流量 | 游戏旁 CTR 异常、供应商弹窗 | 广告与游戏保持安全距离；停用有问题的源/位置 |
| 供应商体验不可控 | iframe 慢、跳转、成人/赌博广告 | 上线前多地区/设备 QA；建立下架开关和供应商黑名单 |
| COPPA 定位漂移 | 视觉、措辞、广告明显吸引低龄儿童 | 坚持 teens and adults；不收集不必要年龄/个人信息；定期内容审核 |
| SEO 规模化滥用 | 标签页爆增、近重复描述 | 索引阈值、canonical/noindex、人工编辑门槛 |
| 单一流量源 | 绝大多数访问来自 Google | 做 Bing、开发者引荐、直接访问、邮件/社媒品牌渠道 |
