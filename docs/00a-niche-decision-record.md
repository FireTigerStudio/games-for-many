# 垂类决策记录：双人浏览器游戏

- 决策状态：已接受，附带游戏供给验收条件
- 决策日期：2026-08-04
- 目标市场：美国、英文、PC 浏览器
- 首发规模：30–50 款人工审核游戏
- 站点受众：casual gamers, teens and adults；不以 13 岁以下儿童为目标人群
- 品牌：Games for Many
- 主域名：gamesformany.com（2026-08-07 已购买）
- 冷启动接入：GameMonetize 官方 iframe 手工录入 10 款；API 延后

## 1. 决策

首站选择 **2 player browser games / 2 player games online** 作为主垂类。

品牌域名采用 `gamesformany.com`，但这不改变首发垂类。`Games for Many` 是可扩展的品牌容器，首页与首批内容继续以双人浏览器游戏为核心；未来只有在双人主题通过供给、收录和用户行为验证后，才扩展 3–4 人、派对和精选休闲多人游戏。

首发优先顺序：

1. 同一键盘、本地双人游戏；
2. 无聊天、无账号、无用户生成内容的在线合作或对战游戏；
3. 双人赛车、体育、街机、策略和轻派对游戏。

2026-08-10 根据供应商准入结果追加执行决策：审核版 MVP 先上线 10 款人工挑选游戏，数据保存在本地 JSON/CSV 中；页面和数据模型不依赖某个 API。后续取得 GamePix `sid` 或其他正式权限后，只替换数据导入方式，不重写页面架构。GameDistribution 未批准前不使用其目录或 iframe。

首页与品牌定位不使用 `kids games`、`games for children`、`unblocked at school` 或 `adult games`。其中 `adult games` 在英文市场通常具有色情含义，不等于“面向成年人”。

## 3. 为什么首站不选另外三类

### IO 游戏

- 需求最大，但核心词 KD 100，新站短期无法以首页竞争；
- 在线联机、昵称、聊天和用户交互更常见，隐私、内容审核与供应商审计成本更高；
- 大量搜索与知名游戏名、仿作和灰色 `unblocked` 词混杂，侵权与品牌安全风险更高。

IO 可以作为双人站后期的受控子分类，但不作为首站总定位。

### 塔防游戏

- 核心词 KD 41、CPC $1.15，商业指标有吸引力；
- 但美国月搜索量仅 880，单独做站的增长天花板较低；
- 关键词经常混入 Bloons、Roblox 等受保护 IP 或攻略/代码意图。

塔防适合作为后续专题或第二个垂类测试，而不是第一站的全部内容。

### 赛车游戏

- 搜索量 5,400，低于双人词；KD 78，高于双人词；
- 容易出现真实汽车品牌、影视角色或知名竞速游戏的未授权仿作；
- 可作为双人站的 `2 player racing games` 子集，降低单一玩法带来的供给风险。

## 4. 商业与产品适配

双人垂类可以同时覆盖：

- 游戏页内由授权发行平台提供的游戏内广告分成；
- 父页面上的 Google AdSense 页面广告；
- `same keyboard`、`local multiplayer`、`co-op`、`versus`、`2 player racing` 等多个清晰子主题；
- “和朋友立即玩”的明确使用场景，利于编辑推荐、榜单和相关推荐内链。

但关键词 CPC 不是站点实际页面 RPM，也不能直接预测收入。最终收益取决于美国流量占比、会话时长、每次访问页数、广告可见率、供应平台填充率和无效流量控制。

## 5. 不可违反的内容与合规边界

1. 只使用发行平台明确授权给已注册发布商的官方 iframe、embed link 或 API 返回链接；公开可访问不等于允许商业转载。
2. 不使用 Pokemon、Mario、Roblox、Minecraft、Fortnite 或其他未授权 IP 的名称、图标、截图、角色和仿作素材。
3. 不收录成人色情、赌博、血腥暴力、仇恨内容，以及主要面向 13 岁以下儿童的游戏。
4. 首发优先无聊天、无账号、无用户生成内容的本地双人游戏；在线多人游戏逐款审核交互功能。
5. 不抓取第三方游戏文件，不绕过平台 iframe，不把平台目录收录视为我方合规背书。
6. 上线必须包含 Privacy Policy、Terms、Cookie Consent、About 和 Contact。
7. 页面广告不得伪装成游戏按钮，不得贴近控制区造成误点，也不得插入供应商 iframe 内。

## 6. 供给验收门槛

审核版 MVP 先以 20 款候选、10 款批准上线作为冷启动门槛。网站获批并取得稳定供应权限后，正式扩充阶段仍应满足：

- 至少发现 50 款候选双人游戏；
- 至少 30 款通过审核并可用于首发；
- 至少 15 款为同键盘或本地双人玩法；
- 每款都有可保存的官方授权来源、平台名称和官方 iframe/embed URL；
- 每款完成 IP、受众年龄、暴力、赌博/成人内容、聊天/账号、控制方式和广告体验审核；
- 同一游戏只选择一个正式供应源，避免重复页面和分成归因冲突。

若无法达到以上门槛，优先调整为“2 player + local multiplayer + selected casual multiplayer”的稍宽定位，而不是通过未经授权的 GitHub、itch.io 或其他站点抓取游戏补数量。

## 7. 下一步验证

1. 选择首个主供应平台和一个备用平台；
2. 注册发布商账号并确认美国公司资料、域名审核、API/iframe 权限和当前分成条款；
3. 先从 GameMonetize 官方目录建立 20 款候选清单并批准 10 款；获批后扩充到 50 款候选并继续人工审核；
4. 通过供给验收后，再把确定的平台、字段和接入流程写入技术架构及需求文档。
